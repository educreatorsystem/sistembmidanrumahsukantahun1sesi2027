PANDUAN MUDAH KEMAS KINI SISTEM BMI SKST 2027
VERSI 4.0.0-tanpa-pin

PERUBAHAN VERSI INI

1. Ibu bapa terus memilih nama untuk mengisi borang, tanpa PIN.
2. Sejarah perubatan mempunyai pilihan Tiada atau Ada penyakit.
3. Jika Ada penyakit dipilih, hanya jenis penyakit perlu dinyatakan.
4. Soalan ubat, pemantauan dan sekatan aktiviti telah dikeluarkan.
5. Ilustrasi header, 314 nama murid dan tema biru merah dikekalkan.
6. Log masuk admin, analisis BMI, eksport dan agihan rumah diteruskan.

A. KEMAS KINI APPS SCRIPT DAHULU

1. Ekstrak ZIP ini dan buka folder apps-script.
2. Buka projek Apps Script yang sedang digunakan sistem anda.
3. Simpan salinan kod lama jika diperlukan.
4. Gantikan SEMUA kandungan Code.gs dengan Code.gs daripada ZIP ini.
5. Gantikan SEMUA kandungan Core.gs dengan Core.gs daripada ZIP ini.
6. Pastikan Data.gs masih wujud dalam projek yang sama. Fail Data.gs
   dalam ZIP mengandungi daftar sebenar yang sama dan boleh digunakan.
7. Simpan semua fail.
8. Pilih fungsi sediakanSistem, kemudian klik Run / Jalankan.
   Fungsi ini mengekalkan akaun admin, daftar aktif dan rekod yang
   telah disimpan. Ia tidak memadam data atau menjana semula rumah.
9. Selepas selesai, klik Deploy > Manage deployments.
10. Pilih deployment yang sedang digunakan dan klik ikon pensel.
11. Pada Version, pilih New version, kemudian klik Deploy.

PENTING: Code.gs DAN Core.gs mesti dikemas kini bersama. Menampal
Code.gs sahaja akan menyebabkan mesej Core.gs belum dikemas kini.
Menekan Save sahaja belum mengemas kini deployment /exec.

Jika ini pemasangan pertama:
- Buka Sheet melalui Extensions > Apps Script.
- Masukkan Code.gs, Core.gs dan Data.gs daripada folder apps-script.
- Gunakan kandungan appsscript.json yang disertakan, dengan runtime
  V8 dan zon masa Asia/Kuala_Lumpur.
- Jalankan sediakanSistem dan benarkan akses projek sekolah.
- Buat deployment jenis Web app, Execute as: Me, dengan akses
  Anyone jika dibenarkan oleh akaun sekolah.
- Akaun awal: nama pengguna admin, kata laluan skst@1234.
  Jika akaun admin telah dipasang, gunakan kata laluan sedia ada.

Database yang digunakan:
https://docs.google.com/spreadsheets/d/1aIVl4toXjKncxGT75oV-GNKwdVEOFMUINIu0Lc2lUAI/edit

B. SEMAK PAUTAN APPS SCRIPT

1. Buka URL Web app yang berakhir dengan /exec.
2. Cari teks "version":"4.0.0-tanpa-pin" dan "configured":true.
3. Jika masih 3.0.0-pin, ulang langkah New version pada deployment
   yang betul. Pastikan Code.gs dan Core.gs baharu telah disimpan.
4. Jika URL Apps Script berubah, buka config.js pada komputer dan
   gantikan nilai apiUrl dengan URL /exec yang baharu.
5. Jika anda menggunakan URL tersendiri sebelum ini, salin URL itu
   ke config.js baharu. Jangan tertinggal tetapan sambungan anda.
6. Nilai requiredVersion perlu kekal 4.0.0-tanpa-pin.

C. KEMAS KINI FAIL DI GITHUB

1. Buka repository sistem anda.
2. Muat naik dan gantikan fail berikut daripada ZIP:
   - index.html
   - styles.css
   - app.js
   - config.js yang mempunyai URL Apps Script anda
   - folder assets bersama kandungannya
3. Pastikan index.html berada terus pada halaman utama repository.
4. Klik Commit changes.
5. Tunggu GitHub Pages selesai membina laman dan muat semula.
6. Jika masih melihat borang lama, muat semula tanpa cache:
   Windows: Ctrl + Shift + R
   Mac: Cmd + Shift + R

Folder apps-script ialah untuk dipasang pada editor Apps Script.
Ia tidak perlu dimuat naik bagi menjalankan laman GitHub Pages.

D. AKTIFKAN DAFTAR JIKA BELUM AKTIF

1. Buka laman dan klik Ruangan Admin.
2. Log masuk menggunakan akaun admin sedia ada.
3. Jika pratonton daftar muncul, semak jumlah 314 murid:
   Kumpulan 1 dan 2: 40 murid setiap kumpulan.
   Kumpulan 3 hingga 8: 39 murid setiap kumpulan.
4. Klik Sahkan & Aktifkan 314 Murid.
5. Jika senarai sudah aktif, teruskan menggunakan dashboard.

E. CARA IBU BAPA MENGISI

1. Taip sekurang-kurangnya dua huruf nama anak.
2. Pilih nama daripada cadangan yang dipaparkan.
3. Kumpulan asal keluar secara automatik dan borang terus terbuka.
4. Isi berat, tinggi dan tarikh pengukuran.
5. Pada sejarah perubatan, pilih:
   Tiada: ruangan jenis penyakit tidak perlu diisi.
   Ada penyakit: nyatakan jenis penyakit, contohnya Asma atau Alahan.
6. Tandakan pengakuan dan klik Hantar Maklumat.
7. Tunggu mesej berjaya sebelum menutup halaman.

Memilih nama lain mengosongkan input anak sebelumnya. Nama mesti
dipilih daripada cadangan; menaip nama sendiri sahaja tidak cukup.
Penghantaran semula mengemas kini rekod bagi StudentID yang sama.
Carian nama membuka borang kosong dan tidak memaparkan ukuran atau
sejarah perubatan yang pernah dihantar. Admin boleh menyemak rekod.

F. PEMBAHAGIAN RUMAH SUKAN

- Draf agihan dijana apabila semua murid aktif mempunyai rekod lengkap.
- Bagi 314 murid, kapasiti rumah ialah 79, 79, 78 dan 78.
- Pengimbangan menggunakan bilangan ahli, taburan BMI, kumpulan asal
  dan bilangan murid yang melaporkan penyakit. Jenis penyakit tidak
  ditafsirkan sebagai tahap kebolehan sukan.
- Admin semak draf, klik Sahkan Semakan dan Terbitkan Keputusan.
- Penjaga boleh memilih nama anak untuk melihat rumah yang diterbitkan.
- Pindaan rekod selepas agihan tidak menukar semua rumah secara automatik.

G. REKOD LAMA DAN PRIVASI

- Struktur database dan StudentID asal dikekalkan.
- Rekod perubatan format lama masih dibaca dan dikira lengkap jika sah.
- Tab akses lama boleh kekal dalam Sheet; versi ini tidak menggunakannya.
- Maklumat kesihatan terdahulu hanya boleh dibaca melalui akaun admin.
- Tanpa pengesahan penjaga, sesiapa yang mempunyai pautan dan memilih
  nama boleh menghantar atau mengemas kini rekod bagi nama itu.
- Simpan database Google Sheet sebagai fail persendirian. Jangan
  terbitkan rekod kesihatan melalui Publish to web atau CSV awam.

H. JIKA ADA RALAT

Core.gs belum dikemas kini:
Salin semula Core.gs daripada ZIP ini, simpan dan deploy New version.

Versi masih 3.0.0-pin:
Semak deployment dan apiUrl dalam config.js. Gunakan URL /exec yang
memaparkan versi 4.0.0-tanpa-pin.

Butang hantar tidak aktif:
Semak nama telah dipilih, berat/tinggi/tarikh lengkap, pilihan Tiada
atau Ada penyakit dijawab, jenis penyakit diisi jika Ada, pengakuan
ditanda dan sambungan sistem sedia.

Nama tidak keluar:
Taip sekurang-kurangnya dua huruf. Pastikan assets/students.json
sudah dimuat naik dan senarai telah diaktifkan oleh admin.

Semua perubahan ini telah diuji secara setempat. Deployment Google
sebenar perlu dikemas kini oleh pemilik akaun mengikut langkah A.
